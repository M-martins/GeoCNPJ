Como funciona o mapa

O geocodebr do Ipea compara endereços com o CNEFE do IBGE. O GeoCNPJ calcula um score e decide quais resultados precisam de revisão. Veja os critérios completos e as fontes.

Os círculos numerados resumem registros na escala atual. Clique para aproximar. Quando vários ocupam a mesma coordenada, clique no número para abri-los em leque.

As cores representam a decisão do GeoCNPJ: verde para aceitação automática, amarelo para aceitação com alerta, vermelho para revisão e cinza para não classificado. O score é uma regra de triagem, não uma probabilidade de acerto. Confira precisão, desvio e empate antes de usar um ponto.
