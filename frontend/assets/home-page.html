Dos dados da Receita ao ponto no mapa.

Escolha o mês dos dados de interesse, prepare os estabelecimentos de um município, obtenha coordenadas e revise o resultado. O GeoCNPJ reúne essas etapas em um projeto e guarda os arquivos em um Acervo que pode ser reutilizado.

Como avançar do arquivo ao mapa

Cada caixa mostra o que entra, o que você faz e o que fica pronto. Se já houver arquivos no Acervo, outro projeto pode usá-los.

  1. 01

    Dados oficiais

    Escolha o mês dos dados de interesse e baixe os ZIPs de Estabelecimentos da Receita para este computador. As tabelas auxiliares entram uma vez e são compartilhadas.

    SAÍDA Arquivos do mês no Acervo
  2. 02

    Base municipal

    Escolha a UF e o município. O GeoCNPJ lê as partes locais, separa os estabelecimentos e acrescenta descrições cadastrais e da CNAE.

    SAÍDA CSV ou Parquet municipal
  3. 03

    Geocodificação

    O motor Python usa o geocodebr do Ipea e dados do CNEFE/IBGE para encontrar coordenadas e classificar a qualidade dos endereços.

    SAÍDA Dados com coordenadas e precisão
  4. 04

    Mapa e revisão

    Explore os pontos, filtre empresas, confira casos incertos e exporte os registros selecionados ou filtrados.

    SAÍDA Mapa e GeoJSON para análise

Base parcial é permitida. Com ao menos uma parte de Estabelecimentos e as tabelas auxiliares, você pode avançar. O GeoCNPJ registra e sinaliza que registros e totais podem estar incompletos.

O Acervo evita repetição. Arquivos oficiais, bases municipais e resultados concluídos podem servir a mais de um projeto no mesmo computador.

LOCALIZAÇÃO

CNEFE/IBGE + geocodebr

O geocodebr em Python usa dados de endereços do CNEFE para estimar coordenadas. A qualidade, a precisão e os casos para revisão acompanham o resultado.

MAPA BASE

OpenStreetMap

Fornece o contexto cartográfico exibido pelo MapLibre. Os pontos dos estabelecimentos são resultados do processamento do seu projeto.

Tecnologia por trás do fluxo

A interface abre no navegador, enquanto os arquivos, o controle das operações e o processamento ficam no computador onde o GeoCNPJ está instalado.

Python e FastAPIInterface e etapas 1–3. O servidor local recebe os comandos do navegador, consulta o catálogo da Receita, organiza as tarefas demoradas e informa seu progresso.
Pandas e PyArrowEtapa 2. A leitura em blocos filtra os ZIPs por município sem extrair toda a base. PyArrow grava Parquet quando esse formato é escolhido.
SQLiteAcervo e etapa 4. Guarda projetos, estados das operações e decisões de revisão; o índice espacial responde aos filtros sem carregar todos os pontos de uma vez.
geocodebr em PythonEtapa 3. Usa endereços do CNEFE/IBGE para propor coordenadas; o GeoCNPJ preserva score, precisão e motivos para que o usuário confira resultados incertos.
MapLibre e OpenStreetMapEtapa 4. MapLibre desenha pontos e agrupamentos; os tiles do OpenStreetMap dão o contexto visual. Os pontos do CNPJ vêm do processamento local.
HTML, CSS e JavaScriptNavegação. Apresentam o passo a passo, a ajuda, o Acervo e os filtros no navegador; as operações pesadas continuam no servidor local.
LEITURA RESPONSÁVEL

Uma coordenada é uma estimativa.

Considere score, precisão, motivo e cobertura dos arquivos antes de usar o mapa para conclusões. Pontos marcados para revisão merecem conferência.

Quando usa a internet
  • Primeira instalação: obtém pacotes Python.
  • Dados oficiais: consulta e baixa arquivos da Receita Federal.
  • Geocodificação: pode baixar insumos CNEFE do IBGE para o cache local.
  • Mapa: carrega o MapLibre pelo unpkg e tiles de tile.openstreetmap.org.
